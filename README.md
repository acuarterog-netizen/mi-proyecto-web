# Mi Proyecto Web

Proyecto web sencillo creado para practicar Git y GitHub. Contiene una página HTML con una estructura básica y mejoras desarrolladas en ramas independientes.

## Tabla de contenido

- [Instalación](#instalación)
- [Estructura](#estructura)
- [Mejoras implementadas](#mejoras-implementadas)

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/acuarterog-netizen/mi-proyecto-web.git
   ```
2. Abre el archivo `index.html` en tu navegador.

## Estructura

- `index.html`: página principal del proyecto.
- `.gitignore`: excluye archivos y carpetas locales innecesarios.
- `.vscode/`: carpeta local excluida del repositorio.
- `README.md`: documentación del proyecto.

## Mejoras implementadas

- Menú de navegación con enlaces internos hacia Inicio y Contacto.
- Tabla HTML con información sobre el horario de clases.
